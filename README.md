
# Student Performance Analysis – Python

A Python-based project for analyzing student academic performance using data analysis techniques.

## Project Overview

This project analyzes student marks in Mathematics, Science, and English. It calculates average marks, identifies high-performing students, and finds the top-performing student.

## Features

- Load student data from CSV
- Calculate average marks
- Filter students based on average marks
- Identify high-performing students
- Find the top-performing student
- Display analysis results

## Technologies Used

- Python
- Pandas
- CSV
- Data Analysis

## Dataset

The dataset contains:

- Student Name
- Mathematics Marks
- Science Marks
- English Marks

## Analysis Performed

- Average marks calculation
- Data filtering
- Top performer identification
- Basic exploratory data analysis
